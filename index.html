M&E Coding kobo

Move submissions from a locked KoboToolbox project into a new copy of the form. Everything runs in your browser; no data is uploaded anywhere.

1. Load the new project's structure

Upload one dummy submission (.xml) from the new project. The app reads its form ID, version and field structure from it.

2. Load the old data

Upload the old submissions: individual .xml files, a .zip of XML files, or a Kobo .csv / .xlsx export (use XML values and headers when exporting). You can select several files.

3. Check the field matching

Fields are matched by name automatically. Change any match with the dropdowns. Unmatched fields are left empty.

4. Create the new XML files

Every file gets the new form ID and version plus a fresh random instanceID, so nothing is flagged as a duplicate.
